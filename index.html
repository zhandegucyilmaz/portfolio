01. Hakkımda

Ağırlıklı olarak backend tarafında çalışan bir Full Stack .NET Developer'ım. C#, .NET, ASP.NET Core MVC, Web API, Entity Framework, MS SQL Server, React ve Python ile kurumsal web uygulamaları geliştiriyorum.

İlaç sektöründe iş geliştirme, kalite, üretim, finans, Ar-Ge, ruhsat ve satın alma birimlerinin süreçlerini dijitalleştiren uygulamaları uçtan uca geliştirdim. Geomatik mühendisliği geçmişimden gelen analitik bakış açısı ve veri modelleme deneyimimle iş ihtiyaçlarını ölçeklenebilir çözümlere dönüştürüyorum.

Claude Code ve GitHub Copilot gibi yapay zeka destekli araçları kod yazma, refactoring, hata ayıklama ve dokümantasyonu hızlandırmak için aktif olarak kullanıyor; üretilen kodu kalite, güvenlik ve sürdürülebilirlik açısından inceleyip test ediyorum.
